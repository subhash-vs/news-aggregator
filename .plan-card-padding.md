# Plan: Add side padding to article cards

## Context

Article cards are newspaper-minimal: only `border-b border-border pb-4` (bottom rule + bottom padding). No horizontal inset, so at 2–3 columns headline text can visually crowd the gap and look like it's overlapping the neighboring column.

## Change

### File: `src/components/ArticleCard.tsx` (line 23)

```tsx
// Before
<article className="flex h-full flex-col border-b border-border pb-4">

// After
<article className="flex h-full flex-col border-b border-border pb-4 px-0 sm:px-3">
```

- `px-0` on mobile (single column — full-width card, no column neighbors)
- `sm:px-3` (0.75rem) from 2-column layout up — text/image get inset from column edges
- Bottom rule still spans full column width (border applies to the full element box)
- Benefits all consumers: NewsPage grids, Top page, Latest page, Bookmarks page

No grid-gap changes (user chose padding only, not gap bump).

## Verification

1. `npm run test` (tsc --noEmit)
2. Visual check at sm/lg breakpoints — cards should no longer look like text runs into the neighboring column
